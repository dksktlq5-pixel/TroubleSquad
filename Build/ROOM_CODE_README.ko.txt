TroubleSquad 방 코드 버전 · 실행 및 참가 방법

준비
1. 이 TroubleSquad 폴더 전체를 친구에게 보내세요. exe만 따로 보내면 실행되지 않습니다.
2. 압축해서 보냈다면 모두 압축을 풀어 주세요.
3. 방장과 친구 모두 Steam을 실행하고 서로 다른 계정으로 로그인하세요.
4. Play_Online.bat을 실행하세요. IP 주소를 입력하지 않습니다.
5. 처음 실행할 때 필수 구성 요소 오류가 나면 Engine/Extras/Redist/en-us/vc_redist.x64.exe를 설치하세요.

방장
1. 로비에서 캐릭터, 맵, 난이도를 선택합니다.
2. 인원 설정을 2~4명으로 선택하고 '방 만들기'를 누릅니다.
3. 화면에 표시되는 숫자 6자리 참가 코드를 친구에게 전달합니다.
4. 친구가 같은 로비에 나타나고 '준비'를 누르면 '게임 시작'이 활성화됩니다.
5. 방장이 '게임 시작'을 누르면 참가자도 같은 전장으로 자동 이동합니다.
   최소 인원은 방장 포함 2명입니다. 방장만 게임을 시작할 수 있습니다.

친구
1. Play_Online.bat 실행 후 캐릭터를 선택합니다.
2. 참가 코드 입력란에 방장이 알려준 6자리 코드를 입력하고 '참가'를 누릅니다.
3. 로비 명단과 방장이 선택한 맵·난이도를 확인합니다.
4. '준비'를 누르고 기다립니다. 게임 시작은 방장이 합니다.
5. 준비 후 캐릭터·맵·난이도가 바뀌어 준비가 취소되었다면 다시 '준비'를 눌러 주세요.

이전 IP 실행 파일
- Play_Host.bat / Play_Join.bat은 이 버전에 포함하지 않습니다.
- Play_Solo.bat은 Steam 연동 없이 혼자 플레이하는 용도입니다. 친구와 할 때는 Play_Online.bat을 사용하세요.
- 방 코드는 Steam 로비 검색용입니다. 실제 게임 통신도 Steam P2P 경로를 사용합니다.

접속이 안 되면
- 두 사람 모두 Steam에 로그인했는지, 같은 버전인지 확인하세요.
- '참가' 전에 '방 만들기'가 완료되어 코드가 표시됐는지 확인하세요.
- 방을 만든 직후 검색되지 않으면 몇 초 기다렸다가 다시 참가해 보세요.
- 코드가 검색되지 않으면 새 방을 만들고 새 코드를 전달하세요.
- 로비 참가 후 친구가 준비했는지, 방장 포함 최소 2명인지 확인하세요.
- 방장이 나가면 새 방에 다시 참가해야 합니다.
- 시작 실패 메시지가 뜨면 방을 나갔다가 새로 만드세요.

조작
WASD 이동 / 마우스 조준 / 기본 무기 자동 공격
E 일반 스킬 / R 궁극기(6레벨 해금) / Tab 능력치
카드 클릭 또는 1·2·3 성장 선택 / Esc 환경설정 열기/닫기

테스트 빌드 안내
Steam 개발 테스트 AppID(480)를 사용합니다.
실제 Steam 방 코드 발급과 P2P 서버 생성은 확인했습니다.
서로 다른 계정·PC 사이의 참가와 장시간 협동 전투는 친구와 플레이하며 추가 확인해야 합니다.

버전 일치
이번 빌드는 방 검색 규격 v3입니다. 두 사람 모두 이번에 전달한 같은 폴더를 사용하세요. 이전 패키지와 섞으면 방을 찾지 못할 수 있습니다.
