전체 Windows 폴더를 유지하세요. exe만 따로 옮기면 실행되지 않습니다.

로비에서 캐릭터와 맵을 선택한 뒤 게임 시작 → 입장 수락을 누르세요.

조작
- WASD: 이동
- 마우스: 조준 / 기본 무기는 자동 공격
- E: 일반 스킬
- R: 궁극기
- 카드 클릭 또는 숫자 1/2/3: 성장 선택
- Tab 누르기: 능력치 확인
- 마우스 휠: 시점 거리 조절
- Esc: 로비로 돌아가기
- 미니맵 옆 톱니바퀴: 음량·화면 설정
