# 전투 VFX 개선 및 검증 기록

기준일: 2026-11-19. 사용량 잔여 10% 미만 시 기능 추가를 멈추고 공유용 패키징으로 전환한다. 커밋과 푸시는 수행하지 않는다.

## 기준과 한계

참고 영상: https://youtu.be/TaGA8xu5LFc

영상 설명의 챕터는 징크스 0:54, 세라핀 21:59, 레오나 42:26, 일라오이 1:03:58, 브라이어 1:25:38,
야스오 1:46:48, 리븐 2:06:34, 오로라 2:26:23, 자야 2:47:57이다. 이번 브라우저 확인은 각 캐릭터 챕터의 짧은 전투 표본이며 모든 스킬의 발동 프레임을 분석한 것은 아니다.
영상 원본의 파티클 소스나 셰이더를 추출한 결과가 아니다. 새로 작성한 형상·입자·머티리얼을 기존 전투 판정에 연결했다.
빌드와 캡처 성공은 영상과의 완전한 시각적 일치를 의미하지 않는다.

## 구현

- 캐릭터별 전투 색: 징크스 분홍, 세라핀 청록, 레오나 금색, 일라오이 주황 산호색, 브라이어 진홍,
  야스오 파랑, 리븐 연두, 오로라 청록, 자야 파랑·보라. 촉수와 깃털 메시의 머티리얼도 함께 보정한다.
- 스킬 시전, 충돌, 범위 파동, 잔광과 입자를 분리했다. 범용 실사 화염을 연속 배치하던 무기 궤적을 대체했다.
- 보호막, 레오나 E/R 영역, 브라이어 광분, 리븐 R, 오로라 E/R, 자야 강화, 야스오 장막은 실제 상태를 보고 갱신한다.
- 일반 무기 효과는 무기 ID를 전달한다. 선택한 캐릭터가 달라져도 무기의 색과 형태가 바뀌지 않는다.
- 적중 효과는 실제 피해 적용 시점을 사용한다. 무기별 0.08초 제한으로 다중 적중 입자의 폭증을 줄인다.
- 파티클과 리본은 소유 캐릭터당 하나의 procedural mesh section으로 합친다. 같은 정점 수에서는 버퍼를 갱신한다.
- 동시 효과 상한은 캐릭터당 96개다. 지속 상태를 보존하고 오래된 일회성 효과부터 교체한다.
- 만료·사망·전투 종료·소유자 제거에 정리한다. 지속 상태는 마지막 갱신 뒤 0.16초 안에 만료된다.
- 전투 반경을 렌더러 내부의 작은 최대치로 잘라내지 않는다. 기본/진화형도 동일한 실제 반경 입력을 받는다.
- 전용 서버에서는 이펙트 액터를 만들지 않는다. 전투 판정은 계속 서버가 처리한다.

## 추가 검증

- 일반 무기 20종의 1~5레벨·기본/진화 수치 200개 구성을 검사했다. 실제 발사기의 피해 발생 시점과 기본 재사용 대기시간도 검사했다.
- 발사기 등 이동형 투사체는 서버에서 비행과 충돌을 계산한다. 비행 전 무피해, 충돌 피해, 벽 반사, 사거리 만료, 개수 상한, 관통 3회 검사가 통과했다.
- 자야·오로라 전용무기 기본/진화·레벨·투사체 능력치 조합 120개를 실제 생성 개수로 검사했다.
- 효과 RPC를 0.05초 주기의 묶음 전송으로 변경했다. 로컬 서버/클라이언트에서 표식 40개 중 40개 수신을 확인했다. 별도 PC의 Steam 중계 검증을 대신하지는 않는다.
- 외곽 지대·지하 세계 실험실·상륙지에서도 일반 무기 효과 갤러리 렌더 캡처를 확인했다.
- 제공된 Niagara 시스템은 활성화·컴파일 상태는 정상이나 진단 캡처에서 표현이 확인되지 않아 제작용 스킬에 연결하지 않았다. 현재 검증된 procedural 입자·리본과 제한된 기존 파티클을 사용한다.

## 검증 방법

`Scripts/VerifyArcadeVfx.ps1`은 수명/상한 검사, 무기 기본·진화 표본, 캐릭터 9종의 E/R 개별 실행을 수행한다.
`-OnlySignatures`는 수명/상한 검사를 다시 수행하고 9종 전용무기의 기본·진화 발사를 각각 실행한다.
`Saved/VfxReview`에 실행 로그와 실제 렌더 캡처를 저장한다. 패키징은 실행하지 않는다.

확인해야 할 나머지 항목은 원본 영상의 캐릭터별 프레임 대조, 장시간 풀빌드 성능,
서로 다른 계정의 협동 플레이에서 이펙트 전달, 4개 맵의 모든 지형·전투 상황에서의 가독성이다.
이 항목들이 남은 상태에서 전체 완성도 100%라고 표시하지 않는다.

## 2026-11-19 Blender 가독성 보강

- Blender에서 Dart, Feather, Crescent, ImpactStar, Mine, Flame 메시 6종을 제작하고 ReadableFX 경로로 임포트했다.
- 메시 정점을 캐시하고 기존 전투 VFX 배치에 합쳐 별도 액터 증식을 피한다. 일반 무기 20종 갤러리에서 6종 모두 실제 로드를 확인했다.
- 투사체 머리와 궤적 폭, 초승달 실루엣, 지뢰와 불꽃 형상을 보강했다. E/R은 일반 적중 섬광보다 높은 표시 우선순위를 가진다.
- 궁극기 검증용 캐릭터를 6레벨로 설정하고 실제 시전 성공 여부를 검사한다. 잠긴 궁극기의 빈 캡처를 통과시키지 않는다.
- Editor 빌드 및 수명/96개 예산 검사 통과. 전체 캐릭터 회귀, 최신 부하 검사와 패키징 검증은 별도 완료 기록이 필요하다.
- 신규 형상은 직접 제작한 메시이며 원작 Niagara 소스를 추출하거나 복제한 자산이 아니다.
