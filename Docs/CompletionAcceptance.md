# TroubleSquad 완료 판정표

기준일: 2026-11-19. 전체 퍼센트 대신 구현과 검증 여부를 분리한다. 아래 미완료 항목이 남아 있으면 100%로 표시하지 않는다.

## 이번 보완

- 이름 있는 증강 32종의 선택·중복 방지·4슬롯 상한·능력치/조건부 효과를 추가했다. 레벨업/접근 카드와 구분되는 보상 대기열을 사용한다.
- 유미 보상을 방어 퀘스트와 연결했다. 현재 120/480/720초에 시작, 원 안의 적 40마리 처치, 제한 90초라는 **자체 테스트 튜닝**이다. 영상에서 측정한 시각이나 원본의 모든 퀘스트 유형을 재현한 것은 아니다.
- 증강 수치 중 원본에 명시되지 않은 거리·확률·주기·중첩 수치는 `SwarmAugments.cpp`의 시험용 값이다. 스토리/극한 해금별 증강 풀 제한은 아직 적용하지 않았다.
- 경험치 구슬의 65초 자동 삭제를 제거했다. 이동 복제, 수집 대상 고정, 지면 기준 획득 반경과 서버 20Hz 수집 갱신을 적용했다.
- 카드 선택 중 이동·스킬 입력을 막았다. 팀원이 선택 중인 경우에도 서버에서 시전을 차단한다.
- 생성 속도·동시 적 상한·체력/피해를 시간대별 설정으로 분리했다. 보스 체력과 팀 인원 보정도 분리했다. 새로운 수치는 원본 수치가 아닌 밸런스 후보이다.
- 일반 적 생성 기준 플레이어를 순환하여 방장 주변에만 적이 생성되던 경로를 수정했다.
- 영구 업그레이드 15종의 구매 상한을 연결하고, 누락된 재생/치명타/투사체/획득 반경/골드/동물 능력 적용을 추가했다. 참가자의 로컬 업그레이드를 서버로 전달하고 기본 이동 속도·방어력도 복제한다.
- 경험치 구슬·회복 팩·치명타·스킬 사용 경력 집계를 추가했다. 폭탄/슈퍼카/혜택/어려움 아트록스 해금은 해당 이벤트/난이도 흐름이 연결되기 전까지 잠금 상태를 유지한다.
- 자동 검사에서 실제 플레이 저장 파일을 갱신하지 않도록 분리했다. 회귀 검사에서 저장 파일 해시도 비교한다.
- 공통 이펙트 머티리얼에 시간에 따른 가장자리 변형·입자 명암 변화를 추가했다. 원본 파티클을 추출한 결과는 아니다.

## 검사 범위 주의

가속 전투 검사는 8배 시간·무적·풀빌드를 사용한다. 실제 성장 속도, 정상 난이도 클리어 가능성, 렌더링 FPS, Steam 중계 품질을 증명하지 않는다.
카탈로그 등록 검사는 각 증강의 모든 상황을 검증한 것이 아니다. 대표 수치·중복·보상 대기열·서버 적용을 별도 검사한다.
기존 공유 폴더 패키지는 이전 검증 빌드이며, 이번 소스 변경이 자동으로 반영되지 않는다.
